# CodeAlpha Image Gallery

## A Modern and Responsive Photography Gallery

## Project Overview

The CodeAlpha Image Gallery is a responsive photography gallery developed using HTML5, CSS3, and Vanilla JavaScript as part of the CodeAlpha Frontend Development Internship – Task 1.

The application provides an interactive photography browsing experience with category filters, full-screen image previews, smooth animations, and responsive layouts.

**Live Demo:** https://ghopikhashrias.github.io/CodeAlpha_ImageGallery/

**GitHub Repository:** https://github.com/GhopikhashriAS/CodeAlpha_ImageGallery

---

## Key Features

- Responsive Gallery Layout: Masonry-style image arrangement for desktop, tablet, and mobile devices.
- Category Filters: Filter images by Nature, Architecture, Portrait, and Travel.
- Interactive Lightbox: View selected photographs in a full-screen preview.
- Image Navigation: Navigate between images using Next and Previous buttons.
- Keyboard Controls: Navigate using arrow keys and close the lightbox using Escape.
- Smooth Animations: Hover effects, transitions, and scroll-reveal animations.
- Accessibility: Keyboard navigation and reduced-motion support.
- Back to Top: Quickly return to the beginning of the page.

## Quick Start

### Option 1 – Run Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. View the website in your browser.

### Option 2 – Clone the Repository

Open the terminal and execute:

```bash
git clone https://github.com/GhopikhashriAS/CodeAlpha_ImageGallery.git
```

Open the downloaded project folder in Visual Studio Code.

### Option 3 – Run Using Python

Open the terminal inside the project folder and execute:

```bash
python -m http.server 3000
```

Open the following address in your browser:

```text
http://localhost:3000/index.html
```

To stop the local server, press `Ctrl + C` in the terminal.
